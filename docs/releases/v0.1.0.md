# hirdir 0.1.0

The first release is the skeleton that every later release builds on: one package that
installs on Ubuntu 26.04, runs behind nginx under any URL prefix, and lets people sign
in and an Admin manage accounts. The inventory itself arrives with 0.2.0.

## New

- **The package.** `hirdir_0.1.0_amd64.deb` installs under `/opt/hirdir` with its own
  Python and every Python dependency, starts a service as the unprivileged `hirdir`
  user, and backs its database up every day.
- **nginx set-up.** `hirdir-setup` adds `hirdir` to a site that already terminates TLS,
  shows the change before making it, and moves `hirdir` to another prefix with
  `--prefix`. The prefix is written in one nginx file and nowhere else.
- **Signing in.** A username and an access code that an Admin sets. The session is a
  signed token kept in the browser's local storage; `hirdir` sets no cookies. Repeated
  wrong codes are slowed down.
- **Ending sessions.** Resetting a code, disabling a user or "Sign out everywhere" ends
  every session that user has, at once.
- **Roles.** View-only, Inventory and Admin, granted to a user or to a user group. A
  user holds the highest role granted either way, and a change takes effect on the next
  request. The last Admin cannot be removed.
- **Service accounts.** Automation uses named tokens that belong to a service account,
  can expire, and are revoked one at a time.
- **Audit trail.** Every change to an account, group, role or token, and every sign-in
  and refused sign-in, is recorded with who, when and through which door.
- **Web UI.** Sign in, users, groups, roles, service tokens, the audit trail and an
  About page, in light and dark.
- **Command line.** `hirdir sign-in`, `whoami` and `users list` talk to the API from any
  machine. `hirdir admin` runs on the server: `create-user`, `reset-access-code`,
  `migrate`, `backup`, `restore`, `check`.
- **API.** Everything above is under `/api/v1`, described by an OpenAPI document that
  is kept in the repository as the contract.
- **Documentation.** Every page is published as HTML and is also installed with the
  package under `/usr/share/doc/hirdir/`. Start with
  [Install and operate](../install.md).

## Additional Notes

- Every component is at its latest production release. Nothing is held back.
- TypeScript 7 no longer offers the interface that the usual OpenAPI type generator and
  typescript-eslint are built on. The web UI's types are generated by the project's own
  script, and the linter is Biome.
- The test client that the server's tests use warns that it will prefer the `httpx2`
  package over `httpx`. The tests pass on `httpx` today. The switch is to be looked at
  for 0.2.0.
- The upgrade check of the package test is skipped in this release, because there is no
  earlier release to upgrade from. The upgrade path was exercised by hand with a
  repacked older version.
- The browser scenario runs in Playwright's container image, so it does not depend on
  the libraries of the build host.
- `hirdir` is licensed under the [Apache License 2.0](../../LICENSE.md).
- Scenarios S01 to S05 of the [build plan](../build-plan.md) pass.
